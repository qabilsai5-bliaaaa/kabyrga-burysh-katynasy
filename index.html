Негізгі теоремалар мен қатынастар

Төмендегі көрсеткіштер сол жақтағы моделятормен тікелей байланысты!

1. Ішкі бұрыштардың қосындысы ∠A + ∠B + ∠C = 180°

Кез келген үшбұрыштың ішкі бұрыштарының қосындысы әрдайым 180°-қа тең.

0° + 0° + 0° 180° ✓

2. Үшбұрыш теңсіздігі a + b > c

Үшбұрыштың кез келген қабырғасы қалған екі қабырғасының қосындысынан кіші болады.

3. Үлкен қабырғаға үлкен бұрыш қарсы жатады

Үшбұрышта үлкен қабырғаға үлкен бұрыш, ал кіші қабырғаға кіші бұрыш қарсы жатады.

4. Синустар теоремасы

a / sin(A) = b / sin(B) = c / sin(C) = 2R

5. Косинустар теоремасы

a² = b² + c² - 2bc · cos(A)
